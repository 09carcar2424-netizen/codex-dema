# Wordfriends Article Draft: Search Console 기초

## WordPress 제목

Search Console 기초: 사이트 상태를 확인하기 전에 알아둘 것

## 추천 슬러그

`search-console-basic`

## 카테고리

수익형 사이트 운영

## 본문 HTML

```html
<section class="wordfriends-article">
  <p><strong>Search Console은 사이트가 Google 검색에서 어떻게 인식되는지 확인하는 도구입니다.</strong></p>

  <p>Search Console을 연결한다고 해서 검색 노출, 색인, 방문자, 수익이 보장되는 것은 아닙니다. 다만 사이트 소유권, 사이트맵 제출, 색인 상태, 검색 문제를 확인하는 데 도움이 되므로 운영 초기부터 기준을 이해해 두는 것이 좋습니다.</p>

  <h2>1. Search Console은 무엇을 확인하나요?</h2>
  <p>Search Console은 Google 검색과 사이트 사이의 상태를 확인하는 관리 도구입니다. 사이트가 검색엔진에 어떻게 발견되고 있는지, 어떤 페이지에 문제가 있는지, 사이트맵 제출 상태가 어떤지 점검할 수 있습니다.</p>

  <ul>
    <li>사이트 소유권 확인</li>
    <li>사이트맵 제출 상태</li>
    <li>색인 가능 여부</li>
    <li>검색 노출과 클릭 참고 데이터</li>
    <li>모바일 사용성 또는 페이지 관련 문제</li>
  </ul>

  <h2>2. 연결 전에 소유권을 먼저 정리합니다</h2>
  <p>Search Console은 Google 계정과 연결됩니다. 도메인, 호스팅, WordPress, Google 계정은 고객 소유를 원칙으로 준비하는 것이 안전합니다.</p>

  <ul>
    <li>Google 계정을 고객이 직접 관리할 수 있나요?</li>
    <li>도메인 DNS 설정 권한을 고객이 확인할 수 있나요?</li>
    <li>WordPress 관리자 권한이 준비되어 있나요?</li>
    <li>비밀번호나 인증 코드를 문의창에 그대로 남기지 않도록 안내되어 있나요?</li>
  </ul>

  <h2>3. 소유권 확인 방식은 상황에 따라 다릅니다</h2>
  <p>Search Console에서 사이트를 추가할 때는 소유권 확인이 필요합니다. 도메인 전체를 확인하는 방식과 특정 URL 주소를 확인하는 방식이 있으며, 어떤 방식을 쓸지는 도메인 관리 권한과 운영 구조에 따라 달라질 수 있습니다.</p>

  <ul>
    <li>도메인 속성: DNS 레코드로 도메인 전체를 확인하는 방식</li>
    <li>URL 접두어 속성: 특정 주소 단위로 확인하는 방식</li>
    <li>HTML 파일 또는 태그 방식: 사이트 파일이나 Head 영역에 확인 코드를 넣는 방식</li>
  </ul>

  <p>어떤 방식이든 소유권 확인은 검색 결과를 보장하는 절차가 아니라, 사이트 관리 권한을 확인하는 절차입니다.</p>

  <h2>4. 사이트맵은 사이트 구조를 안내하는 파일입니다</h2>
  <p>사이트맵은 검색엔진이 사이트 안의 주요 페이지를 찾는 데 참고하는 파일입니다. WordPress에서는 SEO 플러그인이나 기본 기능을 통해 사이트맵이 만들어지는 경우가 많습니다.</p>

  <ul>
    <li>사이트맵 주소가 열리는지 확인합니다.</li>
    <li>중요한 페이지와 글이 사이트맵에 포함되는지 확인합니다.</li>
    <li>Search Console에 제출한 뒤 상태를 기다립니다.</li>
    <li>오류가 나오면 URL, 플러그인, 공개 상태를 다시 확인합니다.</li>
  </ul>

  <h2>5. 색인은 시간이 걸릴 수 있습니다</h2>
  <p>사이트맵을 제출하거나 URL 검사를 했다고 해서 모든 페이지가 바로 색인되는 것은 아닙니다. Google은 사이트 품질, 중복성, 접근 가능성, 정책 요소 등을 종합적으로 판단합니다.</p>

  <ul>
    <li>새 사이트는 데이터가 쌓이는 데 시간이 걸릴 수 있습니다.</li>
    <li>품질이 낮거나 중복이 많은 페이지는 색인되지 않을 수 있습니다.</li>
    <li>robots 설정이나 비공개 상태가 있으면 검색엔진이 접근하지 못할 수 있습니다.</li>
    <li>색인 여부와 방문자 수는 별개의 문제입니다.</li>
  </ul>

  <h2>6. Search Console 데이터는 참고 지표입니다</h2>
  <p>Search Console에는 노출, 클릭, 평균 순위 같은 데이터가 표시될 수 있습니다. 하지만 이 데이터는 운영 상태를 참고하기 위한 지표이며, 수익이나 순위를 보장하는 자료가 아닙니다.</p>

  <ul>
    <li>노출은 검색 결과에 표시된 참고 횟수입니다.</li>
    <li>클릭은 검색 결과에서 사이트로 들어온 참고 횟수입니다.</li>
    <li>평균 순위는 검색어와 기간에 따라 달라질 수 있습니다.</li>
    <li>데이터가 적을 때는 성급하게 판단하지 않는 것이 좋습니다.</li>
  </ul>

  <h2>7. Wordfriends가 돕는 범위</h2>
  <p>Wordfriends는 고객 소유 계정과 도메인을 기준으로 Search Console 연결 준비, 사이트맵 확인, 기본 오류 점검, 고객 포털 상태 정리를 돕습니다. 다만 검색 노출, 색인, 순위, 트래픽, AdSense 승인, 수익을 보장하지 않습니다.</p>

  <div class="wordfriends-article-cta">
    <strong>Search Console 연결 전 기본 상태를 먼저 확인하세요.</strong>
    <p>도메인 소유권, 사이트맵, WordPress 공개 상태, 필수 페이지를 함께 보면 다음 작업 순서를 더 쉽게 정할 수 있습니다.</p>
    <p><a href="/구축절차/">구축절차 보기</a> · <a href="/가이드-faq/">가이드/FAQ 보기</a> · <a href="/문의/">상담 문의</a></p>
  </div>
</section>
```

## 검수 메모

- 검색 노출, 색인, 순위, 트래픽, 수익 보장 표현 없음
- 고객 소유 계정/도메인 원칙 포함
- 비밀번호/인증 코드 공유 주의 포함
- Search Console을 결과 보장이 아니라 상태 확인 도구로 설명
