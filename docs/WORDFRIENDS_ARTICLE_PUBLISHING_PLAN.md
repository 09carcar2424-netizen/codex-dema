# Wordfriends Article Publishing Plan

## 목적

Wordfriends 가이드/FAQ 글을 WordPress에 발행할 때 사용할 운영표입니다.
각 글은 고객 교육, 상담 전 이해도 향상, 서비스 신뢰 형성을 목적으로 하며 AdSense 승인, 수익, 트래픽, 검색 순위를 보장하지 않습니다.

## 발행 기본 원칙

- 글은 먼저 `초안`으로 등록하고 모바일/PC 화면을 확인한 뒤 공개합니다.
- 카테고리는 가이드/FAQ 허브 구조와 맞춥니다.
- 제목은 질문형 또는 체크리스트형으로 쓰되 보장형 표현을 피합니다.
- 모든 글 하단에는 `문의`, `구축절차`, `가이드/FAQ` 중 최소 2개 이상의 내부 링크를 둡니다.
- AdSense, 수익, 도메인 이력, 샌드박스 경과는 참고/준비/검토 표현으로만 안내합니다.
- 고객 소유 계정 원칙과 비밀번호/API 키 공유 금지 원칙은 관련 글에 반복해서 넣습니다.

## 추천 발행 순서

1. `애드센스 기본 이해`
   - 가장 넓은 고객 관심사입니다.
   - 가이드/FAQ 허브의 첫 안내 글로 적합합니다.

2. `도메인 구매 전 체크`
   - 상담 전 도메인 수, 소유권, 후보 검토 질문을 줄일 수 있습니다.
   - 문의 전환과 잘 맞습니다.

3. `네임서버 연결`
   - 도메인 구매 후 실제로 막히는 지점을 해결합니다.
   - 구축절차 페이지와 연결하기 좋습니다.

4. `필수 페이지 준비`
   - WordPress 구축과 AdSense 준비를 이어줍니다.
   - 서비스 페이지와 정책 페이지의 의미를 설명합니다.

5. `AdSense 신청 전 체크리스트`
   - 가장 민감한 주제이므로 앞선 글들이 준비된 뒤 발행합니다.
   - 신청 전 점검표로만 안내하고 결과 보장을 피합니다.

## WordPress 등록 체크리스트

- 제목이 보장형으로 읽히지 않는가?
- 카테고리가 가이드/FAQ 허브 구조와 맞는가?
- 추천 슬러그가 짧고 영문으로 되어 있는가?
- 본문 첫 문단이 고객 질문에 바로 답하는가?
- 하단 CTA 링크가 정상 동작하는가?
- 모바일에서 제목, 목록, CTA가 너무 길게 깨지지 않는가?
- AdSense 승인, 수익, 트래픽, 검색순위 보장 문구가 없는가?
- 비밀번호, API 키, 로그인 정보 공유 금지 안내가 필요한 글에 포함되어 있는가?
- 고객 소유 계정/도메인 원칙이 필요한 글에 포함되어 있는가?

## 내부 링크 기준

- `/가이드-faq/`: 모든 교육형 글의 기본 복귀 링크
- `/구축절차/`: 도메인, 네임서버, WordPress 준비 글에서 우선 연결
- `/문의/`: 상담 전환이 필요한 글에서 우선 연결
- `/서비스/`: WordPress 구축, 필수 페이지, 운영 범위 설명 글에서 연결
- `/고객-포털/`: 고객 포털 사용 안내 글 작성 시 연결

## 발행 후 확인

- WordPress 글 URL이 정상 열리는지 확인합니다.
- 모바일에서 본문 폭과 CTA가 자연스럽게 보이는지 확인합니다.
- 가이드/FAQ 페이지의 허브 섹션에서 해당 글로 연결할 위치를 기록합니다.
- Search Console 색인 요청은 사이트 운영 상태를 본 뒤 진행합니다.
- 발행 후 결과는 검색 노출이나 수익 보장이 아니라 운영 현황 기준으로만 검토합니다.
