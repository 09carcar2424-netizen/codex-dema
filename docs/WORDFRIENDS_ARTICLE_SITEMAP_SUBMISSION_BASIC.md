# Wordfriends Article Draft: 사이트맵 제출 이해하기

## WordPress 제목

사이트맵 제출 이해하기: 검색엔진에 사이트 구조를 알려주는 방법

## 추천 슬러그

`sitemap-submission-basic`

## 카테고리

수익형 사이트 운영

## 본문 HTML

```html
<section class="wordfriends-article">
  <p><strong>사이트맵은 검색엔진에게 사이트 안의 주요 페이지와 글 구조를 알려주는 안내 파일입니다.</strong></p>

  <p>사이트맵을 제출한다고 해서 검색 노출, 색인, 방문자, 수익이 보장되는 것은 아닙니다. 다만 Search Console에서 사이트 구조를 확인하고, 검색엔진이 주요 URL을 발견하는 데 참고할 수 있으므로 운영 초기에 점검해두면 좋습니다.</p>

  <h2>1. 사이트맵은 무엇인가요?</h2>
  <p>사이트맵은 사이트에 어떤 페이지와 글이 있는지 정리한 파일입니다. 보통 XML 형식으로 만들어지며, WordPress에서는 기본 기능이나 SEO 플러그인을 통해 자동 생성되는 경우가 많습니다.</p>

  <ul>
    <li>홈페이지 주요 페이지</li>
    <li>발행된 글</li>
    <li>카테고리 또는 글 목록</li>
    <li>검색엔진이 참고할 수 있는 URL 구조</li>
  </ul>

  <h2>2. 사이트맵 주소는 어디에서 확인하나요?</h2>
  <p>WordPress 사이트에서는 보통 아래와 같은 주소에서 사이트맵을 확인할 수 있습니다. 사용하는 플러그인이나 설정에 따라 주소가 다를 수 있습니다.</p>

  <ul>
    <li><code>/wp-sitemap.xml</code></li>
    <li><code>/sitemap.xml</code></li>
    <li><code>/sitemap_index.xml</code></li>
  </ul>

  <p>사이트맵 주소가 열리지 않으면 WordPress 공개 상태, SEO 플러그인 설정, 캐시, robots 설정을 함께 확인해야 합니다.</p>

  <h2>3. Search Console에 왜 제출하나요?</h2>
  <p>Search Console에 사이트맵을 제출하면 Google이 사이트 구조를 참고할 수 있습니다. 이것은 검색 결과를 보장하는 절차가 아니라, 사이트 안의 주요 URL을 알려주는 절차에 가깝습니다.</p>

  <ul>
    <li>사이트맵이 정상적으로 읽히는지 확인할 수 있습니다.</li>
    <li>제출한 URL 수와 상태를 참고할 수 있습니다.</li>
    <li>오류가 있는 경우 점검 단서를 얻을 수 있습니다.</li>
    <li>새 글 발행 후 사이트 구조가 잘 반영되는지 확인할 수 있습니다.</li>
  </ul>

  <h2>4. 제출 후 바로 검색에 나오나요?</h2>
  <p>아닙니다. 사이트맵 제출은 색인 요청이나 검색 노출 보장이 아닙니다. Google은 페이지 품질, 중복성, 접근 가능성, 정책 요소, 사이트 신뢰도 등을 종합적으로 판단합니다.</p>

  <ul>
    <li>제출 완료와 색인은 다른 상태입니다.</li>
    <li>색인되어도 검색 상위 노출이 보장되지는 않습니다.</li>
    <li>신규 사이트는 데이터가 쌓이는 데 시간이 걸릴 수 있습니다.</li>
    <li>품질이 낮거나 중복된 페이지는 색인되지 않을 수 있습니다.</li>
  </ul>

  <h2>5. 사이트맵 제출 전 체크할 것</h2>
  <p>사이트맵을 제출하기 전에 기본 공개 상태를 먼저 확인하는 것이 좋습니다. 사이트 자체가 비공개이거나 중요한 페이지가 빠져 있으면 제출해도 기대한 상태 확인이 어렵습니다.</p>

  <ul>
    <li>사이트가 HTTPS로 정상 접속되나요?</li>
    <li>홈, 서비스, 문의, 이용약관, 개인정보처리방침 같은 기본 페이지가 열리나요?</li>
    <li>발행된 글이 사이트맵에 포함되어 있나요?</li>
    <li>검색엔진 차단 설정이 켜져 있지 않나요?</li>
    <li>robots.txt가 중요한 페이지를 막고 있지 않나요?</li>
  </ul>

  <h2>6. 오류가 나올 때 확인할 것</h2>
  <p>Search Console에서 사이트맵 오류가 보이면 먼저 주소와 공개 상태를 확인합니다. 대부분은 주소 오타, 비공개 상태, 플러그인 설정, 캐시 문제에서 시작됩니다.</p>

  <ul>
    <li>사이트맵 URL을 브라우저에서 직접 열어봅니다.</li>
    <li>WordPress 읽기 설정에서 검색엔진 차단 여부를 확인합니다.</li>
    <li>SEO 플러그인의 사이트맵 기능이 켜져 있는지 봅니다.</li>
    <li>캐시 플러그인이나 보안 설정이 사이트맵 접근을 막지 않는지 확인합니다.</li>
    <li>도메인 주소가 www/non-www 또는 http/https로 섞이지 않았는지 확인합니다.</li>
  </ul>

  <h2>7. Wordfriends가 돕는 범위</h2>
  <p>Wordfriends는 고객 소유 도메인과 계정을 기준으로 사이트맵 주소 확인, Search Console 제출 상태 점검, WordPress 공개 상태 확인, 고객 포털 진행 상태 정리를 돕습니다. 다만 사이트맵 제출, 색인, 검색 노출, 순위, 트래픽, AdSense 승인, 수익을 보장하지 않습니다.</p>

  <div class="wordfriends-article-cta">
    <strong>사이트맵 제출 전 기본 공개 상태부터 확인하세요.</strong>
    <p>도메인 연결, SSL, 필수 페이지, 글 공개 상태, Search Console 연결을 함께 보면 다음 점검 순서를 더 쉽게 정할 수 있습니다.</p>
    <p><a href="/가이드-faq/">가이드/FAQ 보기</a> · <a href="/구축절차/">구축절차 보기</a> · <a href="/문의/">상담 문의</a></p>
  </div>
</section>
```

## 검수 메모

- 검색 노출, 색인, 순위, 트래픽, 수익 보장 표현 없음
- 사이트맵 제출을 결과 보장이 아니라 구조 안내/상태 확인 절차로 설명
- 고객 소유 도메인/계정 원칙 포함
- Search Console 글과 자연스럽게 연결됨
