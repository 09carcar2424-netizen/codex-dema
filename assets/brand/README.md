# Wordfriends Brand Assets

Wordfriends 브랜드 로고와 파비콘 원본입니다.

## 파일

- `wordfriends-logo.svg`: 홈페이지/문서용 가로형 로고
- `wordfriends-mark.svg`: SNS, 정사각형 썸네일, 작은 로고용 심볼
- `wordfriends-favicon.svg`: 파비콘/사이트 아이콘 원본
- `wordfriends-favicon-512.png`: WordPress 사이트 아이콘 업로드 권장 파일
- `wordfriends-favicon-192.png`: PWA/브라우저 아이콘용 보조 파일
- `wordfriends-favicon-32.png`: 브라우저 탭 파비콘용 보조 파일

## 사용 원칙

WordPress 공식 로고를 그대로 결합하면 공식 제휴나 인증 브랜드처럼 오해될 수 있으므로, 이 자산은 WordPress 운영 서비스를 연상시키는 자체 원형 W 마크로 제작했습니다.

## WordPress 적용

1. 관리자에서 `외모 > 사용자 정의하기 > 사이트 아이덴티티`로 이동합니다.
2. 사이트 아이콘에는 `wordfriends-favicon-512.png`를 업로드합니다.
3. 테마가 로고 업로드를 지원하면 `wordfriends-logo.svg` 또는 PNG 변환본을 업로드합니다.
4. SVG 업로드가 막히면 PNG 변환본을 사용합니다.
