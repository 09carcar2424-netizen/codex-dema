# Wordfriends WordPress Publishing Guide

## 발행 전 준비

WordPress 관리자에서 먼저 아래 카테고리를 만듭니다.

- 애드센스 가이드
- 도메인/호스팅/서버
- WordPress 구축

선택 카테고리로 이후 추가할 수 있는 항목:

- 수익형 사이트 운영
- 자동화 n8n/MAKE
- FAQ/공지

## 공통 등록 방식

1. WordPress 관리자에 로그인합니다.
2. `글 > 새 글 추가`로 이동합니다.
3. 제목은 `posts-manifest.json`의 `title` 값을 사용합니다.
4. URL 슬러그는 `slug` 값을 사용합니다.
5. 카테고리는 `category` 값을 선택합니다.
6. 본문은 같은 폴더의 `sourceFile` HTML 파일 내용을 복사해 붙여넣습니다.
7. 상태는 먼저 `초안`으로 저장합니다.
8. PC와 모바일 미리보기에서 제목, 목록, CTA 링크를 확인합니다.
9. 보장형 표현이 없는지 마지막으로 확인한 뒤 공개합니다.

## 발행 전 검수

- 승인 보장, 수익 보장, 트래픽 보장, 검색순위 보장 표현이 없는가?
- 도메인 이력, 샌드박스 경과가 결과 보장처럼 읽히지 않는가?
- 고객 소유 계정/도메인 원칙이 필요한 글에 들어가 있는가?
- 비밀번호, API 키, 로그인 정보 공유 금지 안내가 필요한 글에 들어가 있는가?
- CTA 링크가 실제 페이지로 정상 이동하는가?
- 모바일에서 긴 제목과 버튼이 깨지지 않는가?

## 발행 후 확인

- 글 URL이 정상 열리는지 확인합니다.
- 가이드/FAQ 페이지에서 해당 글로 연결할 위치를 기록합니다.
- Search Console 색인 요청은 사이트 운영 상태를 확인한 뒤 진행합니다.
- 발행 결과는 검색 노출이나 수익 보장이 아니라 운영 현황 기준으로만 검토합니다.
